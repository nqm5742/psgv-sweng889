# Module 3 Bike Demand Application

## Project
Develop a small application that predicts hourly bike rental demand
using the Seoul Bike Sharing Demand dataset.

The original dataset is located at:

data/raw/SeoulBikeData.csv

## Development Guidelines
- Use Python.
- Prefer simple, readable implementations suitable for teaching.
- Keep the original raw dataset unchanged.
- Keep data preparation, model training, evaluation, and application code separated.
- Explain significant proposed changes before making them.
- Work only on the task currently requested.
- Do not automatically proceed to later stages of the project.
- Inspect relevant files before making claims about the project.
- Run and validate generated code when appropriate.
- Report relevant results, assumptions, limitations, and problems.
- Avoid unnecessary abstractions or additional dependencies.
- Ask before performing destructive Git operations or deleting project files.
